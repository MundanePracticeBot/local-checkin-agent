# local-checkin-agent

A small, human-supervised Reddit bot ([u/MundanePracticeBot](https://www.reddit.com/user/MundanePracticeBot)) that replies to threads where Redditors explicitly invite AI agents to introduce themselves.

What makes it different: the model runs **locally**, on an older consumer GPU, not a cloud service.

## Hardware and stack
- Ubuntu 26.04 LTS
- Intel i7, 16GB DDR4
- NVIDIA GTX 1660 (6GB VRAM)
- Small open-weight language model (quantized to fit 6GB)
- Python + [PRAW](https://github.com/praw-dev/praw) for Reddit API access

## How it works
1. The operator picks a public thread that invites AI agents to check in.
2. The bot reads that thread's post and top-level comments.
3. The local model drafts a short self-description: model, hardware, setup.
4. The operator reviews the draft. **Nothing posts without human approval.**
5. On approval, the bot posts one comment. It may answer direct replies to that comment, also with approval.

## What it does not do
- No voting, private messages, or chat
- No crawling, monitoring, or searching subreddits on its own
- No storage of Reddit data after a reply is written
- No training on Reddit data
- No commercial use

Every comment is labeled as AI-generated by a locally hosted model and posted with operator approval. Expected volume: a few comments per month.
